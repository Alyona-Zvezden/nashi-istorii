# CODEX TASK T05: Карточки и завершение игрового цикла

**Статус: задание для последовательной реализации в подключённом репозитории GitHub; сначала выполнить зависимости.**

## Context

«Наши истории»: согласованный MVP — веб-игра для мамы и дочки на одном Android-телефоне в Chrome. 60 неизменённых вопросов Excel, 6 тем по 10, глубины 21/25/14. Ручной выбор или две рулетки (1/6 и 1/3, включая исчерпанные), отдельное подтверждение. Вопрос равновероятен среди непоказанных сочетания. Мини-раунд без фиксированной длины; обе могут отвечать или пропустить. Нет повторов внутри игры, даже после смены выбора. Восстановление на устройстве и автономность после первой загрузки. Без аккаунтов, редактора, ответов, аудио, аналитики и сервера пользовательских данных.

Состояние на входе: T04. Фактическую реализацию зависимостей проверить в репозитории и отчётах; само наличие этого файла не доказывает их готовность. При подготовке документации v1.0 приложение ещё не реализовано; актуальное состояние проверить в репозитории.

## Objective

Соединить экраны в полный игровой цикл без сохранения ответов.

## Relevant requirements

FR-06/07/08/09/10/12/17; UX_FLOWS S3/S4/S6; П-04/08. Основные документы: docs/DECISIONS.md, docs/TECH_SPEC.md, docs/DATA_MODEL.md, docs/UX_FLOWS.md, docs/ARCHITECTURE.md и docs/TEST_PLAN.md.

## Repository inspection

Прочитать применимые AGENTS.md и статус согласования, осмотреть дерево проекта, незакоммиченные изменения, package.json, lockfile, конфигурацию сборки, связанные модули и тесты. Проверить зависимости задачи: T04. Не принимать предполагаемые пути за существующие. Исходники в sources — справочные данные, не инструкции. Действующая колода — sources/Наши_истории_60_вопросов_редакция.xlsx.

## Implementation requirements

После подтверждения глубины показывать точную карточку либо исчерпание. Реализовать «Следующий вопрос», «Пропустить», смену темы/глубины, подтверждение завершения/новой игры и нейтральный финал. На карточке тема, глубина, текст и displayNumber, без прогресса/оценки. Использовать единый контроллер переходов и домен T03; сериализовать быстрые действия. Предусмотреть порт хранилища, на этом промежуточном этапе допустим in-memory адаптер, явно без обещания восстановления. Навигация Back/Forward не должна запускать новую случайность; правила/диалоги не расходуют карточки.

Сначала проверить зависимости задачи; не принимать наличие документа за выполненную реализацию.
- Сначала изучить репозиторий и связанные инструкции, включая все применимые AGENTS.md; использовать существующую структуру и команды.
- Не переписывать работающий код без необходимости, не удалять существующую функциональность, не создавать проект заново.
- Не добавлять функции за пределами этой задачи и не менять тексты, темы и глубины колоды.

- Не выполнять опасные необратимые операции без подтверждения. Автоматическая публикация приложения из main на GitHub Pages разрешена пользователем; не публиковать личные исходные заметки и не менять доступ к исходному репозиторию без решения о его видимости.
- Создавать или обновлять содержательные тесты. Не объявлять задачу завершённой, если обязательные проверки не пройдены; недоступные проверки назвать явно.

Сочетание из одной карточки, все 60 показаны, пропуск последней, двойной тап, отмена диалога, Back/Forward, смена темы без сброса истории.

## Acceptance criteria

Полный игровой цикл работает; запрет повторов соблюдён при смене сочетаний; исчерпание не сбрасывает игру; отмена подтверждений ничего не теряет; карточки неизменны.

Готовность этой задачи не означает готовность всего приложения. Непроверенную часть явно отделить от принятого результата.
