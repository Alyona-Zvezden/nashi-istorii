# CODEX TASK T03: Чистая игровая логика

**Статус: задание для последовательной реализации в подключённом репозитории GitHub; сначала выполнить зависимости.**

## Context

«Наши истории»: согласованный MVP — веб-игра для мамы и дочки на одном Android-телефоне в Chrome. 60 неизменённых вопросов Excel, 6 тем по 10, глубины 21/25/14. Ручной выбор или две рулетки (1/6 и 1/3, включая исчерпанные), отдельное подтверждение. Вопрос равновероятен среди непоказанных сочетания. Мини-раунд без фиксированной длины; обе могут отвечать или пропустить. Нет повторов внутри игры, даже после смены выбора. Восстановление на устройстве и автономность после первой загрузки. Без аккаунтов, редактора, ответов, аудио, аналитики и сервера пользовательских данных.

Состояние на входе: T02. Фактическую реализацию зависимостей проверить в репозитории и отчётах; само наличие этого файла не доказывает их готовность. При подготовке документации v1.0 приложение ещё не реализовано; актуальное состояние проверить в репозитории.

## Objective

Реализовать независимые от браузера переходы игры и равновероятный выбор.

Действующая колода — sources/Наши_истории_60_вопросов_редакция.xlsx.

## Implementation requirements

Создать доменные типы, вычисление доступных карточек, внедряемый источник случайности и переходы. Рулетки отдельно выбирают одну из 6 тем/3 глубин с равными шансами, включая исчерпанные. Карточка выбирается среди непоказанных выбранного сочетания; фиксация кандидата добавляет ID в shownIds. Следующий и пропуск сохраняют запрет повтора. Смена выбора оставляет историю, очищает current/depth по DATA_MODEL. Исчерпание не сбрасывает игру. Новая игра создаёт новый sessionId и пустую историю. Модуль возвращает кандидаты/ошибки, не обращается к IndexedDB и не работает с DOM.
