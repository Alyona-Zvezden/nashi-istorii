# CODEX TASK T02: Действующая колода и контроль контента

**Статус: задание для последовательной реализации в подключённом репозитории GitHub; сначала выполнить зависимости.**

## Context

«Наши истории»: согласованный MVP — веб-игра для мамы и дочки на одном Android-телефоне в Chrome. 60 неизменённых вопросов Excel, 6 тем по 10, глубины 21/25/14. Ручной выбор или две рулетки (1/6 и 1/3, включая исчерпанные), отдельное подтверждение. Вопрос равновероятен среди непоказанных сочетания. Мини-раунд без фиксированной длины; обе могут отвечать или пропустить. Нет повторов внутри игры, даже после смены выбора. Восстановление на устройстве и автономность после первой загрузки. Без аккаунтов, редактора, ответов, аудио, аналитики и сервера пользовательских данных.

Состояние на входе: T01. Фактическую реализацию зависимостей проверить в репозитории и отчётах; само наличие этого файла не доказывает их готовность. При подготовке документации v1.0 приложение ещё не реализовано; актуальное состояние проверить в репозитории.

## Objective

Подготовить точный локальный набор 60 карточек и воспроизводимую сверку с исходным Excel.

## Implementation requirements

Прочитать sources/Наши_истории_60_вопросов_редакция.xlsx, лист «Вопросы», строки 2…61, A/B/C. Воспроизвести текст, тему и глубину каждой карточки без редактуры. Однократно назначить q001…q060 и displayNumber 1…60 в исходном порядке; сохранить sourceRow. Использовать утверждённые themeId и deckVersion. ## Files and modules

Локальная колода/справочники, подготовка и проверка контента, unit-тесты. Исходный Excel не менять.

## Edge cases

Скобочные окончания (а)/(ась)/(ой), буква ё, длинное тире, знаки вопроса, неверный уровень, дубли ID, случайная перестановка при повторной генерации.

## Tests

Проверить полное равенство text/theme/depth всех 60 записей; уникальность ID/номеров; исходный порядок; 6×10 и матрицу глубин 21/25/14. Тест не должен сравнивать набор только с его собственной копией.

## Verification

Запустить сверку Excel, unit, typecheck, build. Проверить, что XLSX/TXT и инструменты чтения Excel не попали в production resources.

Пользоваться фактическими scripts репозитория. Предложенные в README команды не считать существующими, пока это не проверено. Не заменять провал теста его удалением, отключением или изменением согласованного поведения.

## Acceptance criteria

Все поля совпадают; матрица соответствует DATA_MODEL; ID стабильны; нет добавленных/исправленных вопросов; воспроизводимая сверка и хеш задокументированы.

Готовность этой задачи не означает готовность всего приложения. Непроверенную часть явно отделить от принятого результата.
