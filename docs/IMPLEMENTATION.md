# Реализация и проверки

22 ноября 2026. Репозиторий Alyona-Zvezden/nashi-istorii; пользователь разрешил Public. Доступ Codex и origin проверены. Pages включён с build_type=workflow, основной выпуск публикуется из main. Рабочий адрес: https://alyona-zvezden.github.io/nashi-istorii/.

## Реализовано

Точная колода 60 вопросов, выбор темы/глубины и равновероятные рулетки с подтверждением, случайная карточка, мини-раунды без ограничителя длины, пропуск, общая история без повторов, исчерпание, смена выбора, завершение/новая игра и краткие правила. Отдельные профили, ответы и записи отсутствуют.

Снимок и activeRelease записываются в IndexedDB одной транзакцией. Интерфейс принимает переход только после transaction complete. Ошибка не стирает старое состояние; повтор использует прежний кандидат. Другие вкладки получают сигнал через локальный BroadcastChannel, а атомарная проверка снимка защищает от перезаписи.

PWA сохраняет весь выпуск, а не только посещённые экраны. После закрытия всех клиентов новый worker продолжает отдавать закреплённый выпуск активной игры. Ошибка установки нового выпуска оставляет прежний рабочим. Восстановление повреждённого сохранения требует явного решения пользователя.

## Проверки

- Сверка всех text/theme/depth с Excel и его SHA-256: пройдена; 6×10 и 21/25/14.
- TypeScript: пройден, включая unit/E2E и конфигурацию браузерных тестов.
- 7 unit-тестов: равные интервалы случайности, полное прохождение без повторов, граничные/повреждённые состояния.
- 13 браузерных сценариев: ручной выбор, рулетки, восстановление, исчерпание, отмена сброса, повреждённое сохранение, неизвестная привязка выпуска с явным восстановлением, abort транзакции, двойной тап, конфликт вкладок, полная колода, холодный офлайн/PWA и мобильные макеты. Двухверсийный сценарий входит в эти 13: частичный сбой B, сохранение A после закрытия вкладок и офлайн-применение B после завершения игры.
- Сборка полного выпуска примерно 52 КБ несжатых ресурсов, существенно ниже 2 МиБ.
- Снимки 360/390/412 CSS px и текст 200% проверены; горизонтальная прокрутка отсутствует.

Локальная среда: Windows, Node.js 26.13.1 LTS, npm 11.20.0, Chromium 159 (Playwright 1.65.1), мобильная эмуляция Pixel 7. Состояние каждого Actions run и фактический опубликованный commit проверяются в GitHub после push; наличие этого отчёта не подменяет результат workflow.

## Ещё не проверено

Реальный Android Chrome, TalkBack, замеры скорости на телефоне семьи и две семейные встречи. Не заявлять полное подтверждение NFR-01/04/05 или продуктовой гипотезы до этих проверок.

## Инженерные уточнения

Выбрана существующая Node LTS 26 вместо первоначальной рекомендации ветки 24: версия 26.13.1 уже установлена и удовлетворяет engines Vite/Vitest. Дополнительные fflate и fast-xml-parser — только dev-зависимости для воспроизводимой независимой сверки Excel; они не входят в приложение.

В development service worker не используется: реальная автономность проверяется на production build. Dev может сообщать о недоступности подготовки офлайна, так как sw.js генерируется только при сборке. Пользователю предназначена production-ссылка, а не dev server.

Очистка браузерных данных удаляет игру. Первое открытие без интернета не поддерживается. Один активный профиль/устройство; синхронизации и экспорта нет.
